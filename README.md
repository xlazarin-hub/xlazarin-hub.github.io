# Lucas Tuzza · Unity & C# portfolio

A static Astro portfolio for xlazarin-hub.github.io. All illustrations are original procedural graphics.

## Local review

With Node.js 22.12+ and npm installed, run `npm install` and `npm run dev`. Run `npm run build` and `npm run preview` to inspect the production build.

Project descriptions live in `src/data/projects.ts`. The review workflow builds the site and checks internal links. When ready to publish, select GitHub Actions as the repository's Pages source and merge into main.
